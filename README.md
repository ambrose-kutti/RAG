## 📖 Overview

The RAG Chatbot is an interactive application designed to provide context-aware answers to user queries by leveraging Retrieval-Augmented Generation (RAG). This system allows users to upload their own PDF documents, which are then processed to create a specialized knowledge base. When a user asks a question, the chatbot intelligently retrieves relevant information from these documents and uses it to inform the responses generated by a large language model (LLM).

This project simplifies the process of interacting with custom data, making it ideal for researchers, students, or anyone needing to extract specific information from a collection of documents without fine-tuning an LLM.

## ✨ Features

-   🎯 **PDF Document Ingestion**: Upload and process multiple PDF files to build a custom knowledge base.
-   🧠 **Contextual Answers (RAG)**: Generates highly relevant and accurate responses by retrieving information from your documents before querying the LLM.
-   💬 **Interactive Chat Interface**: A user-friendly Streamlit interface for seamless conversation.
-   🔍 **Vector Embeddings**: Documents are chunked and converted into vector embeddings using Sentence Transformers, stored efficiently in ChromaDB.
-   🔗 **LangChain Orchestration**: Leverages LangChain for robust RAG pipeline management, including document loading, splitting, embedding, and retrieval.
-   🤖 **OpenAI LLM Integration**: Connects with OpenAI's powerful language models to synthesize answers.
-   📜 **Conversational History**: Maintains a history of interactions within the current session.

## 🚀 Quick Start

Follow these steps to get your RAG Chatbot up and running locally.

### Prerequisites
-   **Python 3.9+**: Ensure you have a compatible Python version installed.
-   **OpenAI API Key**: You'll need an API key from OpenAI to use their language models.

### Installation

1.  **Clone the repository**
    ```bash
    git clone https://github.com/ambrose-kutti/RAG.git
    cd RAG
    ```

2.  **Create and activate a virtual environment** (recommended)
    ```bash
    python -m venv venv
    # On Windows
    .\venv\Scripts\activate
    # On macOS/Linux
    source venv/bin/activate
    ```

3.  **Install dependencies**
    ```bash
    pip install -r requirements.txt
    ```

4.  **Environment setup**
    Create a `.env` file in the root directory and add your OpenAI API key:
    ```bash
    cp .env.example .env
    ```
    Open `.env` and configure your environment variables:
    ```
    OPENAI_API_KEY="your_openai_api_key_here"
    ```
    _Replace `"your_openai_api_key_here"` with your actual OpenAI API Key._

5.  **Prepare your documents**
    Place the PDF documents you want the chatbot to analyze into the `data/` directory.
    ```
    # Example:
    data/
    ├── document1.pdf
    └── document2.pdf
    ```
    _The `data/` directory might be empty initially; create it if it doesn't exist._

6.  **Start the Streamlit application**
    ```bash
    streamlit run chatbot.py
    ```

7.  **Open your browser**
    The command above will automatically open a new tab in your web browser, typically at `http://localhost:8501`. If it doesn't, navigate there manually.

## ⚙️ Configuration

### Environment Variables
The application relies on the `OPENAI_API_KEY` environment variable to authenticate with the OpenAI API.

| Variable         | Description                         | Default | Required |
|------------------|-------------------------------------|---------|----------|
| `OPENAI_API_KEY` | Your secret API key for OpenAI services. | None    | Yes      |

_It is recommended to use a `.env` file for local development to manage this variable securely._
